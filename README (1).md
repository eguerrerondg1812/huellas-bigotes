# Huellas & Bigotes 🐾

Página web de una sola página (pensada para celular) de **Huellas & Bigotes**, tienda virtual de productos para perros y gatos con entregas a domicilio en Lima, Perú.

El cliente puede:
- **Ver productos**: catálogo de 30 productos con filtros por mascota y categoría.
- **Hacer mi pedido**: formulario corto que abre WhatsApp con el mensaje ya redactado.
- **Consultar mi pedido**: formulario con nombre y código de pedido (opcional).

Todos los mensajes se envían al WhatsApp **+51 945 738 238** mediante enlaces `wa.me`.

## Archivos

| Archivo | Descripción |
|---|---|
| `index.html` | Página completa: HTML, CSS, JavaScript, logo e ilustraciones incluidos en un solo archivo. |
| `README.md` | Este documento. |

No necesita instalación, dependencias ni compilación. Solo carga las fuentes Fredoka y Nunito desde Google Fonts.

## Publicar en Vercel

1. Sube `index.html` y `README.md` a la raíz de un repositorio de GitHub.
2. En [vercel.com](https://vercel.com), elige **Add New → Project** e importa el repositorio.
3. En **Framework Preset** deja **Other**; no cambies Build Command ni Output Directory.
4. Pulsa **Deploy**. Cada cambio que subas a GitHub se publicará automáticamente.

## Notas

- Los precios son referenciales y provienen de una investigación de mercado (15/11/2026). La disponibilidad, el precio final y las condiciones de entrega se confirman por WhatsApp.
- Las imágenes de los productos son ilustrativas, no fotografías de los artículos.
- La página no guarda datos personales, no solicita DNI ni datos bancarios y no procesa pagos en línea.
